# v0.2.0 · 关闭 IPv6 选项与休眠断网说明

## 新功能

### 「关闭 IPv6（仅 IPv4）」选项

- 第 2 步「一键切换为 iPad 网卡模式」新增这个复选框。勾选后把 PDP 上下文 1 的 IP 类型设为 `IP`（例如 `AT+CGDCONT=1,"IP","ctnet"`），模块只向运营商申请 IPv4 地址，iPad 不会再拿到 240e 等开头的公网 IPv6 地址。
- 取消勾选并重新执行，可以恢复为 `IPV4V6`（IPv4 + IPv6）。
- 模块已经是 ECM 模式时，只改写 IP 类型并重启，不会重复切换 USB 网卡模式。
- 重启后会读回校验 IP 类型；「恢复原始配置」也会一并恢复备份中的 IP 类型。
- 状态面板的 APN 卡片显示当前 IP 类型（「仅 IPv4」或「IPv4 + IPv6」）。

### 显示版本号

- 页面底部显示当前版本号（取自 `package.json`），反馈问题时可以一并提供。

## 文档

- README 和页面内「iPad 使用说明」新增「已知问题：iPad 休眠后断网」：合盖或锁屏休眠再唤醒后，「以太网」仍在，但拿不到 IP（为空或 169.254.x.x），手动固定 IP 也无效，只能重新插拔模块。
- 给出应对办法：使用期间关闭「锁定/解锁」，需要时把「自动锁定」设为「永不」；已经断网时拔插 USB 线；经常合盖、长时间挂机时改用支持 USB 4G 模块的随身路由器。
- 已在真机上确认这版模块固件不支持 `AT+QNETDEVCTL` 和 `AT+QMAP`，本工具无法从模块侧修复休眠断网。
- 常见问题新增「不想让 iPad 拿到 240e 开头的公网 IPv6 地址」。
- 新增 `AGENTS.md`，记录项目约束、代码结构和真机验证情况，供 AI 编程助手参考。

## 升级说明

- 已经用 v0.1.0 切换为 ECM 的模块无需重新配置，可以继续使用。
- 想关闭 IPv6：更新后连接模块，在第 2 步勾选「关闭 IPv6（仅 IPv4）」并执行。
- 本版本新增的写入只涉及 PDP 上下文 1 的 IP 类型；仍然不改动 USB 身份，修改 IMEI 的指令仍被拒绝。

```bash
cd DJI4G-iPadUSBtool
git fetch --tags
git checkout v0.2.0
npm ci
npm run dev
```

也可以下载本页下方的源代码压缩包，解压后在目录中执行 `npm ci` 和 `npm run dev`。
