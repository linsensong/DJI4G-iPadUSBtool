# v0.1.0 · 首个版本

DJI4G-iPadUSBtool 的第一个版本：在电脑上用 Chrome / Edge 把大疆一代 4G 模块（DJI Cellular，USB `2ca3:4006`）切换为 USB ECM 网卡，让 Wi-Fi 版 iPad 通过 USB-C 直接用 SIM 卡流量上网。iPad 上不需要安装任何 App。

## 主要功能

### 连接模块

- **USB 直连（WebUSB）**：适合 macOS / Linux / Android，免驱动。
- **串口（Web Serial）**：适合 Windows，需要先安装移远 Quectel USB 驱动。
- **演示模式**：用模拟模块完整走一遍流程，没有硬件也能先熟悉操作。
- 自动检测运行环境：在 iPad / iPhone 上打开时提示 iPad 端无需安装程序；页面不是 localhost / https，或浏览器不支持 USB 访问时给出提示。

### 模块状态

- 显示 USB 网卡模式、SIM 卡与运营商、蜂窝网络注册状态、信号强度、APN（PDP 上下文 1）、USB 身份和 IMEI（部分隐藏）。

### 一键切换为 iPad 网卡模式

- 按 SIM 卡自动推荐 APN：中国电信 `ctnet`、中国移动 `cmnet`、中国联通 `3gnet`、中国广电 `cbnet`；也可以保留当前设置或自定义。
- 执行前列出将要发送的 AT 指令，执行时依次设置 APN（`AT+CGDCONT`）、切换为 ECM（`AT+QCFG="usbnet",1`）、重启模块（`AT+CFUN=1,1`）。
- 模块重启后自动重连并读回校验；没能自动重连时，页面会提示手动「重新连接模块」。
- 执行前检查 SIM 卡、网络注册、射频状态和 USB 音频功能，发现问题给出提醒。
- 模块已经是 ECM 模式且 APN 正确时，直接提示无需修改。

### 备份与恢复

- 首次连接时自动把原始配置备份到本机浏览器存储；同一块模块（按 IMEI 区分）第一次的备份不会被覆盖。
- 可以下载备份文件，也可以导入之前下载的备份文件。
- 「恢复原始配置」一键写回备份并校验，方便把模块装回无人机；没有备份时可以只把 USB 网卡模式改回 0（QMI）。

### AT 指令调试台

- 内置信号、运营商、网络注册、网络制式、APN、IP 地址、USB 网卡模式等常用查询。
- 改写 USB 身份、恢复出厂参数、固件下载、关机、飞行模式等危险指令需要二次确认。
- 修改 IMEI 的指令（`AT+EGMR=1`）直接拒绝发送。

### iPad 使用说明

- 页面内附 iPad 端操作步骤和常见问题，以及 macOS / Windows / Linux / Android 的电脑端连接说明。

## 安全与隐私

- 只写入 `usbnet` 和 PDP 上下文 1（APN）两项，不改动模块的 USB 身份（`AT+QCFG="usbcfg"`）。
- 没有后端，不收集、不上传任何数据；IMEI、IMSI、ICCID 等信息只在你的浏览器中显示。

## 运行环境

- 桌面版 Chrome 或 Edge，通过 <http://localhost:5173> 或 https 地址打开。
- Node.js：推荐 24 LTS（至少 24.15.0）；也支持 22.22.2 或更高的 22.x，以及 26 或更高版本。
- 基于 React 19、Vite 8 和 TypeScript 6.0，使用 Vitest 5 测试。

## 使用方法

```bash
git clone https://github.com/linsensong/DJI4G-iPadUSBtool.git
cd DJI4G-iPadUSBtool
git checkout v0.1.0
npm ci
npm run dev
```

也可以下载本页下方的源代码压缩包，解压后在目录中执行 `npm ci` 和 `npm run dev`。然后用 Chrome 打开 <http://localhost:5173>。

## 已知问题与验证情况

- 已在真机上确认：macOS 上的 Chrome 能通过 WebUSB 直连模块并收发 AT 指令；切换为 ECM 后，iPad 能识别为「以太网」，拿到 `192.168.225.x` 地址并正常上网。
- iPad 锁屏或休眠后可能断网，需要重新插拔模块（v0.2.0 补充了详细说明和应对办法）。
- 尚未在真机上验证：完整的「恢复原始配置 → 一键切换 → 自动重连 → 校验」流程、模块重启后浏览器能否不弹窗自动重连、Windows 上的 Web Serial 连接。
